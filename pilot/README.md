# 파일럿 코드 (참고용)

본 분석 전에 돌려본 코드. 수정하지 않음. 본 분석은 `src/common.py` 기준.

- `ssb_network_analysis.py`: 구조 지표, 노출 통계 S 순열검정, kNN 범위 곡선, 케스케이드
- `layers5.py`: 6개 분야(통화 포함, 지역기구는 임시 목록) 연도 차이・따라 함 검사, 46개국 제외 비교
- `diffusion_figures.py`, `diffusion_check.py`: figures/ 그림 1~5

경로가 `SSB-Tax-Database-Aug23.csv` 같은 파일명 기준이라 실행하려면 `data/raw/`에서 돌려야 함.
