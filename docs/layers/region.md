# 지역 계층 (A)

대륙・소지역・국경・지역기구 4개 계층. 코드와 결과는 `layers/region/`.

```bash
python layers/region/make_layer.py   # 4개 계층 전부: 엣지 → 1단계 → 강건성 → 도입 여부
```

- 모든 결과는 `src/common.py` 함수를 그대로 씀 (가짜 세계 1,000개, seed 42)
- 대륙 계층은 다른 분야가 따라 할 수 있는 예시로 만든 것. `build()` 순서를 그대로 쓰면 됨

## 계층 만들기

### 대륙 (`continent`)

- `countries.json`의 `region` (Africa, Americas, Asia, Europe, Oceania) 그대로

### 소지역 (`subregion`)

- `countries.json`의 `subregion`. 값이 없으면 대륙으로 채움

### 국경 (`border`)

- 그룹이 아니라 쌍이라서 `countries.json`의 `borders`로 엣지를 직접 만듦 (`group = border`)
- nodes 204개국에 없는 이웃(영토 등)은 뺌
- 한쪽에만 이웃으로 적혀 있어도 쌍 하나로 셈

### 지역기구 (`igo`)

**기구 15개**: EU, ECOWAS, SADC, EAC, COMESA, ECCAS, GCC, ASEAN, CARICOM, SICA, Mercosur, Andean, PIF, SAARC, LOAS (아랍연맹)

- 파일럿 임시 목록과 같은 주요 지역통합기구
- 전 세계 기구(UN・WHO 등)와 대륙 전체 기구(AU・OAS)는 뺌 → 대륙 계층과 겹치기만 함
- COW 기구 335개를 다 쓰면 나라 쌍 86%가 연결돼서 검정이 의미 없음

**회원 기준**

- 1990~2023년 중 한 번이라도 **정회원** (COW 값 1). 준회원(2)・옵서버(3)는 뺌
- 탈퇴한 나라도 회원 기간이 있으면 넣음 (예: 영국 EU)
- 연도와 상관없는 계층으로 씀. 가입 연도는 `layer_igo_membership.csv`에 남겨둠

**COW 보충 (`igo_supplement.csv`)**

| 이유 | 행 |
|---|---|
| COW EAC 코딩 오류 (BWA・ZMB 등이 들어가 있음) → EAC는 COW를 안 쓰고 전부 이 표로 대체 | KEN, TZA, UGA, BDI, RWA, SSD, COD |
| 2015년 이후 가입 | COM(SADC 2017), TUN(COMESA 2018) |
| COW는 국가만 다뤄서 빠진 PIF 비국가 회원 | COK, NIU, PYF, NCL |

**결과**: 160개국이 하나 이상 가입 (2개 이상 가입 35개국), 기구별 회원 5(Andean)~28(EU)개국

## 결과

### 1단계: 같은 그룹 도입국끼리 도입 시기가 가까운가 (계층 전체 `ALL`)

| 계층 | 도입국 | 도입국 쌍 | 실제 평균 연도 차 | 가짜 세계 평균 | p |
|---|---|---|---|---|---|
| 대륙 | 114 | 1,456 | 7.97년 | 9.16년 | **0.001** |
| 소지역 | 112 | 381 | 8.28년 | 9.19년 | **0.042** |
| 국경 | 82 | 106 | 7.52년 | 9.19년 | **0.022** |
| 지역기구 | 99 | 508 | 7.74년 | 9.16년 | **0.001** |

**그룹별로 보면** (p < 0.05만)

- 대륙: 아프리카 (6.56년, p 0.005). 아메리카・유럽은 오히려 가짜 세계보다 멀음 (p 0.97, 0.95)
- 지역기구: GCC (1.2년, p 0.005), LOAS (1.89년, p 0.003), SADC (2.8년, p 0.002), ECCAS (3.18년, p 0.019). EAC・COMESA는 경계선 (0.053, 0.052)
- 지역기구 중 EU・Mercosur는 반대 방향 (p 0.97) → 같은 기구라도 시기가 흩어짐
- 그룹별 도입국 쌍이 적은 곳(3~21쌍)이 많아서 그룹별 p는 참고만

### 강건성: 다른 요인을 걸러도 유지되나 (p)

| 계층 | basic | income_db | budget_year | health_obj |
|---|---|---|---|---|
| 대륙 | 0.001 | 0.001 | 0.002 | 0.001 |
| 소지역 | 0.042 | 0.130 | 0.059 | 0.020 |
| 국경 | 0.022 | 0.036 | 0.027 | 0.019 |
| 지역기구 | 0.001 | 0.002 | 0.006 | 0.003 |

- 대륙・국경・지역기구는 어떤 성격 안에서 섞어도 유의함
- **소지역은 소득 안에서 섞으면 사라짐** (p 0.130) → 소지역 효과는 비슷한 소득 나라끼리 묶인 효과일 수 있음

- 지역기구만 도입 여부에서는 경계선. 시기(1단계)는 뚜렷한데 여부는 약함
- 소득 안에서만 섞어도 결론 같음 (11/22, `docs/analysis/adoption_income.md`): 대륙 p 0.008 (2016 등급)・0.003 (2023 등급), 소지역 0.002・0.001, 국경 0.030・0.023, 지역기구 0.113・0.111 (basic부터 0.05 넘음)

### 해석

- 네 계층 모두 같은 그룹 도입국끼리 시기가 우연보다 가까움
- 지역기구 효과는 GCC・LOAS・SADC・ECCAS 같은 **중동・아프리카 기구**가 끌고 감. EU는 반대
- 대륙 효과도 대부분 아프리카에서 나옴 → 지역기구와 대륙이 같은 신호를 보는 것일 수 있음 (2단계에서 분리)
- 유의한 결과도 "같은 지역・기구 나라끼리 시기가 우연보다 묶임"까지만 말함. **따라 했다(확산)고 단정하지 않음**

- 선은 '연결'과 '시기'이지 '영향'이 아님

## 한계

- 지역기구를 연도와 상관없는 계층으로 씀 → 도입 당시 회원이 아니었던 나라도 연결됨 (예: SSD는 EAC 2016년 가입). 가입 연도를 반영한 검사는 V3에서
- 기구 15개는 파일럿 목록을 그대로 씀. 선정 기준(경제통합 수준 등)을 따로 정하지 않음
- 국경은 육지 국경만. 바다 건너 가까운 나라(예: 영국-프랑스)는 연결 안 됨 → 48개국 고립 (대부분 섬나라)
- `countries.json`의 소지역 구분은 UN 지리 구분 기준이라 정치・경제적 묶음과 다를 수 있음
