## 2. 공통 (넷 다)

**계층마다 내는 결과 4개** (`docs/DIRECTORY_SPEC.md` 형식)

| 파일 | 함수 | 뜻 |
|---|---|---|
| `result_<이름>.csv` | `stage1()` | 1단계: 같은 그룹 도입국 쌍 연도 차이 vs 가짜 세계 |
| `robustness_<이름>.csv` | `robustness()` | 1-1단계: 소득・예산법 연도・건강 목적이 같은 나라끼리만 섞은 가짜 세계 |
| `adoption_<이름>.csv` | `adoption_test()` | 1-2단계: 미도입국까지, 같이 하거나 같이 안 하나 |
| 의심 국가 제외 | `analysis/exclude_checked.py` (A가 한꺼번에) | 연도 확인 안 된 나라 빼도 유지되나 |

**슬라이드**: 자기 분야 부분은 각자 만듦 (계층 만든 방법 1장 + 결과 1장 정도). 숫자는 `result_*.csv`와 `docs/` 문서에서 그대로 가져옴

**발표 (11/22 결정)**: 발표는 **서영・서현** 둘이 함. 수정・승아는 자기 슬라이드마다 **발표 메모**(발표자가 말할 내용 2~3줄, 슬라이드 노트 칸)를 달아서 11/27까지 넘김. 질문 답변은 발표자 둘이 하고, 분야별 세부 질문은 맡은 사람이 보탬

| 순서 | 발표자 | 내용 (제안, 둘이 조정) |
|---|---|---|
| 앞부분 | 서영 | 도입(질문, 공통 원인) → 데이터・연도 검증 → 네트워크 만들기(이분 투영, 멀티플렉스) → 1단계・검증 결과 → 2단계(각 분야 몫) |
| 뒷부분 | 서현 | 2-1단계(다른 대륙끼리, 따라 함) → 확산 경로 그림 → V1 가상 실험 → 결론 메시지 → 한계 |

**표현 규칙** (발표・보고서 공통)
- "따라 했다"고 쓰지 않음 → "같은 그룹끼리 시기가 우연보다 가까웠다"
- 확산 경로 화살표는 "순서"이지 "영향"이 아님
- 미도입 = "2023년까지 안 함"
- p 0.01 미만 "뚜렷함", 0.01~0.05 "약함". 검사를 많이 했으므로 0.03 근처 하나에 큰 의미를 두지 않음
- 따라 함 결과는 "없음"이 아니라 **"강한 따라 함은 없음, 약한 따라 함은 배제 못 함"** (V1, `validation.md` 2장)
- 1단계・따라 함 결과는 전체 섞기와 대륙 안 섞기를 나란히. 둘 다 보정 후 0.05 미만이면 "남음", 하나만이면 "약한 힌트" (11/22 팀 결정. V1: 전체 섞기는 대륙 시기 차이를 따라 함으로 잘못 잡기도 함)

| 언어・식민을 2단계에 따로 넣을지 | ✅ 따로 (2단계 6×6) |

| 해석 규칙 | ✅ (11/22) 두 섞기 다 보정 후 0.05 미만 → "남음", 하나만 → "약한 힌트". 식민 남음(단 영국 그룹 의존), 지역기구 약한 힌트. 언어는 보정 후 둘 다 0.05 넘음(전체 0.647, 대륙 안 0.120) → **"남지 않음"** (11/22). 보정 전 대륙 안 0.020은 표에 숫자만 보여 주고 "힌트"라고 부르지 않음 (보정 전 p로 살리면 규칙을 결과에 맞춰 바꾸는 것) |
| 대륙 정의 | ✅ `countries.json` region 그대로 (11/22). 결과 본 뒤 바꾸면 1단계부터 다 바뀜. 북・남미를 한 대륙으로 본 것은 한계로 적음 |

### 주의
- 따라 함 검사: 2-1단계(다른 대륙 쌍)에서는 약함. V1 결과 → 강한 따라 함(β ≈ 4)은 88% 잡지만 약한 따라 함(β ≤ 1)은 34% 이하만 잡음. 그래서 "없다"가 아니라 **"강한 따라 함은 없고 약한 것은 배제 못 함"**으로 말함. 언어・식민 전체 계층에서는 1~2・1~3년 p 0.015~0.037(보정 전, 대륙 안에서도 남음) → 11/26 회의에서 같이 봄 (`validation.md` 2장)
- 다른 대륙 식민 도입국 쌍의 78%가 영국 그룹 → 영국 연결 제외 결과(보조 검증)를 같이 보여줌
