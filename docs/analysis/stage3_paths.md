# 3단계: 확산 경로 실제 vs 가짜 (B)

코드: `analysis/stage3_paths.py` (계산, 약 1분) → `analysis/stage3_figures.py` (그림, 약 5초)
결과:
- `stage3_path_comparison.csv`: 계층 × 섞는 방식 × 지표, 실제 경로 수・가짜 평균・가짜 95% 범위・p
- `stage3_path_nulls.csv`: 가짜 세계 1,000개 각각의 경로 수 (그림 2용)
- `stage3_path_directed_edges.csv`: 실제 연결마다 먼저 도입 → 나중 도입 방향, 간격
- `stage3_paths_1_3.csv`: 실제 1~3년 간격 A → B → C 경로 목록
- `stage3_group_path_diagnostics.csv`: 그룹별 경로 수, 그 그룹을 빼면 경로가 얼마나 줄어드는지
- 그림: `figures/stage3_확산경로_예시_실제vs가짜.png`, `figures/stage3_경로수_실제vs가짜.png`

## 1. 무엇을 보나

연결된 나라끼리 **먼저 도입한 나라 → 나중에 도입한 나라**로 화살표를 그리면 '확산 경로'처럼 보임. 그런데 도입 연도가 아무렇게나 정해져도 화살표는 늘 생김 → **연도를 섞은 가짜 세계에서도 같은 그림을 그려서, 실제가 더 촘촘한지(간격이 짧은지, 1~3년 간격으로 이어지는 경로가 많은지)** 비교함

- 화살표는 '순서'이지 '영향'이 아님. 발표・보고서에서도 "영향을 줬다"고 쓰지 않음
- 언어・식민 계층만 (B 계층). 1990~2023 도입국 114개국 사이 연결만
- 가짜 세계: 연결은 그대로, 114개국 도입 연도만 섞음 (전체에서 / 대륙 안에서만). seed 42, 1,000개

## 2. 그림 1: 예시 (아랍어권 11개국)

`figures/stage3_확산경로_예시_실제vs가짜.png`

- 화살표 규칙: 나라마다 같은 그룹에서 **가장 최근에 먼저 도입한 나라** → 그 나라 (파일럿 그림과 같은 규칙)
- 실제 평균 간격 **2.3년**, 가짜 세계 1,000개 평균 **3.1년** → 실제가 더 촘촘해 보이지만 **p = 0.137** (우연 범위 안)
- 오른쪽은 가짜 세계 첫 번째 하나 (평균 4.7년). 가짜에서도 '확산 경로'처럼 보이는 그림이 나온다는 걸 보여주려는 것
- 파일럿 그림(`figures/fig3_확산경로_실제vs가짜.png`, 11/14)은 그대로 둠. 이 그림이 현재 데이터(114개국) 기준

## 3. 그림 2: 1~3년 간격 경로 수 (`stage3_path_comparison.csv`)

A → B → C 경로 = A–B, B–C가 둘 다 실제 연결이고, B가 A보다 1~3년 늦게, C가 B보다 1~3년 늦게 도입

| 계층 | 섞는 방식 | 실제 경로 | 가짜 평균 (95% 범위) | p |
|---|---|---|---|---|
| 언어 | 전체 | 1,302 | 1,381 (893~2,043) | 0.575 |
| 언어 | 대륙 안 | 1,302 | 1,379 (945~1,920) | 0.609 |
| 식민 | 전체 | 1,044 | 711 (429~1,112) | 0.042 |
| 식민 | 대륙 안 | 1,044 | 801 (515~1,226) | 0.103 |

- **언어**: 실제 경로 수가 가짜와 같은 수준 → 1~3년 간격으로 이어지는 경로가 우연보다 많지 않음
- **식민**: 전체 섞기에서 p 0.042(약함). 계층 2개 Bonferroni(0.025)는 못 넘고, 대륙 안에서 섞으면 0.103 → 대륙별 시기 차이로 일부 설명됨
- 간격 제한 없는 경로(`simple_paths`)는 두 계층 모두 가짜보다 많지 않음 (p 0.80~0.99)

### 그룹별 (`stage3_group_path_diagnostics.csv`, 도입국 5개 이상)

- 경로는 큰 그룹에 몰림: 언어 1,302개 중 영어권을 빼면 318개만 남음(984개 줄어듦), 식민 1,044개 중 영국 연방(`samecol_GBR`)을 빼면 151개
- → 식민 경로가 가짜보다 많은 것도 영국 그룹에 기댐. 2-1단계 영국 제외 결과(`stage2_1.md` 6절, 영국 빼면 p 0.77)와 같은 방향

## 4. 읽는 법 (다른 결과와 같이)

- 1단계에서는 언어・식민 그룹끼리 도입 시기가 우연보다 **가까움** (같은 시기에 몰림)
- 그런데 연결을 따라 **1~3년 간격으로 이어지는 사슬**은 우연보다 많지 않음 (언어), 약하게 많음 (식민, 영국 그룹 의존)
- V1(`validation.md` 2장): 따라 함 검사는 약한 따라 함(β ≤ 1)을 대부분 못 잡음 → "사슬이 없다"가 아니라 **"강한 사슬은 안 보인다"**까지
- 발표용 문장: "확산 경로처럼 보이는 화살표는 연도를 섞은 가짜 세계에서도 비슷하게 나온다. 실제가 더 촘촘하다는 근거는 약하다"
