# 2단계: 겹침・각 분야 몫・공유 분야 수 (A)

코드: `analysis/stage2.py` (약 5초)
결과: `analysis/stage2_pairs.csv`, `stage2_overlap.csv`, `stage2_share.csv`, `stage2_shared_count.csv`, `stage2_exclude_random.csv`

## 왜 하나

1단계는 분야마다 따로 봄 → 대륙・지역기구・언어・식민이 다 유의하게 나왔지만, 이 분야들은 같은 나라 쌍을 많이 공유함. 대륙이 같은 나라는 같은 지역기구에 들고, 같은 종주국 식민지는 같은 언어를 씀. **여러 분야를 한꺼번에 놓고 각 분야가 따로 설명하는 몫**이 남는지 봄

## 방법

1. **나라 쌍 표** (`stage2_pairs.csv`): 204개국 모든 쌍 20,706개 한 줄씩. 분야별 연결 0/1(민감도용 `subregion, border, trade3, trade10` 포함), 공유 분야 수 `n_shared`(6개 분야 기준), 둘 다 분석 도입국이면 연도 차이 `gap`
2. **겹침 표** (`stage2_overlap.csv`): 분야 × 분야. `n_both` 공통 쌍, `jaccard` = 공통 ÷ 합집합, `share_of_row` = 행 분야 쌍 중 열 분야로도 연결된 비율. `base` = 204개국 쌍 / 도입국 쌍
3. **각 분야 몫** (`stage2_share.csv`): 도입국 쌍 6,441개에서
   `연도 차이 = b0 + b_대륙 × 대륙 + b_지역기구 × 지역기구 + … + b_무역 × 무역` (최소제곱)
   - `coef` < 0 = 다른 분야를 같이 넣고도 그 분야로 연결된 쌍이 시기가 더 가까움 (단위: 년)
   - **p는 가짜 세계로**: 나라 쌍은 서로 독립이 아니라(한 나라가 쌍 113개에 들어감) 보통 회귀 p를 못 씀. 1단계와 똑같이 도입국끼리 연도를 섞은 가짜 세계 1,000개(seed 42)에서 계수를 다시 구하고, 가짜 계수가 실제 이하인 비율 = p (한쪽). 연결 구조는 그대로 두고 연도만 섞는 방식 (QAP와 같은 생각)
4. **공유 분야 수** (`stage2_shared_count.csv`): 도입국 쌍을 6개 분야 중 몇 개를 공유하는지(0, 1, 2, 3, 4+)로 나눠 평균 연도 차이 vs 가짜 세계. `all`・`excl46`・`unsure46`
5. **나라 빼기 비교 기준** (`stage2_exclude_random.csv`): `excl46`・`unsure46`과 같은 수의 도입국을 무작위로 200번 빼고 각 분야 몫을 다시 구함 (`exclude_checked.py`와 같은 방식, 반복마다 가짜 세계 300개). 도입국이 줄어 검정력이 떨어진 탓인지, 뺀 나라들이 효과를 받치던 것인지 구분
   - `rand_coef_median`: 무작위로 뺐을 때 계수 중앙값
   - `rand_share_p05`: 무작위로 빼도 p < 0.05가 나오는 비율 (p 눈금이 약 1/300이라 대략으로만)
   - `rand_share_weaker`: 무작위로 뺀 계수가 실제 이상(효과가 같거나 약함)인 비율. **작으면 뺀 나라들이 그 효과를 받치던 것**

- 대륙 안 섞기에서 같은 대륙 칸들이 다 사라지는 건 당연함 (대륙별 시기 차이를 가짜 세계에 남기므로). 이 열은 다른 대륙 칸을 보려고 둠
- **예외: 대륙을 넘는 지역기구 20쌍은 매우 가까움** (1.95년 vs 9.12년, 대륙 안 섞기도 p 0.011). 20쌍 전부 **아랍연맹(LOAS)**, 걸프 5개국(UAE・바레인・사우디 2017, 오만・카타르 2019)과 북아프리카 4개국(모리타니 2014, 이집트 2016, 튀니지 2018, 모로코 2019) 사이 → 2-1단계 지역기구 '약한 힌트'와 같은 쌍. 아랍어권과도 같은 나라들이고, 걸프 쪽은 걸프협력회의 공동 소비세 합의(`docs/layers/language.md`)라는 공통 원인이 있어 나라 간 확산 근거로 쓰지 않음
- `unsure46`(95개국): 같은 결론. 같은 대륙 안 기구 +0.21년 (p 0.57), 국경 +0.73년 (p 0.77), 대륙만 −1.33년 (p 0.008), 대륙 넘는 기구 15쌍 p 0.007 (대륙 안 0.049). 20쌍 중 연도 의심 국가는 튀니지 하나
