# 2단계: 겹침・각 분야 몫・공유 분야 수 (A)

코드: `analysis/stage2.py` (약 2초)
결과: `analysis/stage2_pairs.csv`, `stage2_overlap.csv`, `stage2_share.csv`, `stage2_shared_count.csv`

## 왜 하나

1단계는 분야마다 따로 봄 → 대륙・지역기구・언어・식민이 다 유의하게 나왔지만, 이 분야들은 같은 나라 쌍을 많이 공유함. 대륙이 같은 나라는 같은 지역기구에 들고, 같은 종주국 식민지는 같은 언어를 씀. **여러 분야를 한꺼번에 놓고 각 분야가 따로 설명하는 몫**이 남는지 봄

- **언어・식민은 따로 셈 (6×6)**. 겹침이 Jaccard 0.37뿐이라 합치면 정보가 사라짐 (`docs/analysis/stage2_1.md` 3번 질문 ②)
- 지역은 대륙으로 대표. 소지역・국경은 민감도로만 (아래 '모형 민감도')
- 보조 계층(`layers/language/supplementary/`)은 안 씀

## 방법

1. **나라 쌍 표** (`stage2_pairs.csv`): 204개국 모든 쌍 20,706개 한 줄씩. 분야별 연결 0/1(민감도용 `subregion, border, trade3, trade10` 포함), 공유 분야 수 `n_shared`(6개 분야 기준), 둘 다 분석 도입국이면 연도 차이 `gap`
2. **겹침 표** (`stage2_overlap.csv`): 분야 × 분야. `n_both` 공통 쌍, `jaccard` = 공통 ÷ 합집합, `share_of_row` = 행 분야 쌍 중 열 분야로도 연결된 비율. `base` = 204개국 쌍 / 도입국 쌍
3. **각 분야 몫** (`stage2_share.csv`): 도입국 쌍 6,441개에서
   `연도 차이 = b0 + b_대륙 × 대륙 + b_지역기구 × 지역기구 + … + b_무역 × 무역` (최소제곱)
   - `coef` < 0 = 다른 분야를 같이 넣고도 그 분야로 연결된 쌍이 시기가 더 가까움 (단위: 년)
   - **p는 가짜 세계로**: 나라 쌍은 서로 독립이 아니라(한 나라가 쌍 113개에 들어감) 보통 회귀 p를 못 씀. 1단계와 똑같이 도입국끼리 연도를 섞은 가짜 세계 1,000개(seed 42)에서 계수를 다시 구하고, 가짜 계수가 실제 이하인 비율 = p (한쪽). 연결 구조는 그대로 두고 연도만 섞는 방식 (QAP와 같은 생각)
4. **공유 분야 수** (`stage2_shared_count.csv`): 도입국 쌍을 6개 분야 중 몇 개를 공유하는지(0, 1, 2, 3, 4+)로 나눠 평균 연도 차이 vs 가짜 세계

- 무역은 쌍 수가 적어(169) 어느 분야와도 거의 안 겹침

### 각 분야 몫 (`main`, 114개국)

| 분야 | 계수 (년) | p | 1단계 혼자 p |
|---|---|---|---|
| **continent** | **−1.22** | **0.008** | 0.001 |
| igo | −0.33 | 0.310 | 0.001 |
| language | −0.51 | 0.221 | 0.026 |
| **colony** | **−1.56** | **0.017** | 0.003 |
| income | +0.35 | 0.993 | 0.621 |
| trade | +0.69 | 0.693 | 0.074 |

- **대륙과 식민만 남음.** 같은 대륙이면 다른 연결이 같아도 1.2년, 같은 식민 관계면 1.6년 더 가까움
- **지역기구・언어는 혼자 볼 때는 유의했지만 같이 넣으면 사라짐** → 지역기구 효과는 대륙에, 언어 효과는 식민에 대부분 겹쳐 있음
- 소득・무역은 혼자도, 같이도 효과 없음 (소득 p 0.99 = 같은 소득 등급 쌍이 다른 연결을 맞추면 오히려 약간 멀다는 뜻이지만 크기 0.35년)
- 검사 6개 Bonferroni 기준(0.05 ÷ 6 = 0.0083)으로는 대륙만 겨우 통과, 식민은 못 넘음

- 섞는 방식(소득・예산법 연도・건강 목적)을 바꿔도 대륙・식민만 남는 결론 그대로
- **대륙 대신 소지역을 넣으면 지역기구가 살아남** → 지역기구 효과는 '같은 대륙'과 겹치는 부분. 소지역 자체는 대륙이 없으면 효과 없음. '지역' 분야의 효과는 대륙 수준에서 나타남
- 국경은 대륙・지역기구를 넣은 뒤 남는 몫이 없음
- `unsure46`(검증에서 확인 안 된 19개국 뺌)에서도 대륙・식민 p < 0.05 유지. `excl46`(46개국 전부 뺌)은 둘 다 0.117로 약해짐. 다만 46개국을 빼면 도입국이 114 → 68개로 줄어 검정력 자체가 떨어짐 (같은 수를 무작위로 뺀 비교는 `exclude_checked.md`처럼 아직 안 함)

### 공유 분야 수

| 공유 분야 수 | 도입국 쌍 | 실제 평균 연도 차이 | 가짜 평균 | p |
|---|---|---|---|---|

- 분야 하나만 공유하는 쌍은 가짜와 차이 없고, **2~3개 공유하는 쌍부터 1.3~1.5년 가까움**
- 4개 이상은 쌍이 적어(232) p 0.07. 공유 수가 늘수록 계속 가까워지는 모양은 아님
- 0개 공유 쌍이 가짜보다 먼 것(p 1.0)은 나머지 쌍이 가까운 것의 반대편 (전체 평균은 섞어도 거의 같음)

## 해석 한계

- 유의해도 '연결된 쌍끼리 도입 시기가 묶임'까지만. 따라 했는지(확산)는 2-1단계・추가 검증 V1~V3과 같이 봐야 함

- 연결은 모두 연도와 상관없는 계층 (지역기구 가입 시기, 무역 2010~2020 평균 → 각 계층 문서 '한계')
- 계수는 선형 회귀 하나의 결과. 분야끼리 상호작용(예: 같은 대륙 + 같은 식민)은 안 봄
