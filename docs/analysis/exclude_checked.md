# 연도 의심 국가 제외 검사 (전 계층)

코드: `analysis/exclude_checked.py` (약 40초)
결과: `analysis/exclude_checked.csv`, `analysis/exclude_checked_random.csv`

## 왜 하나

- 도입 연도 검증 결과는 `nodes.csv`에 **반영하지 않기로 함** (2026-11-21, 이유는 `docs/layers/income.md` '연도 검증')
- 대신 연도가 의심스러운 나라를 연도 비교에서 빼도(`in_analysis = 0`, 연결은 유지) 결론이 유지되는지 봄
- 도입 여부 검사는 연도를 안 쓰므로 해당 없음

## 버전

| 버전 | 뺀 나라 | 남은 분석 도입국 | 뜻 |
|---|---|---|---|
| `all` | 0 | 114 | 기본 (각 계층 `result_*.csv`와 같음) |
| `excl46` | 46 | 68 | 연도 검증한 46개국 전부 |
| `excl60` | 60 | 54 | + 추가 의심 14개국 전부 |
| **`unsure46`** | **19** | **95** | **46개국 중 검증에서 '맞음'이 아닌 나라 (수정 8, 모름 11)** |
| `unsure60` | 32 | 82 | + 14개국 중 '맞음'이 아닌 나라 13 |

- 46개국은 '연도가 틀린 나라'가 아니라 **예산법 연도 의심(`budget_year = 1`) 50개국 중 검증한 46개국**. 27개국은 검증에서 맞음 → `excl46`은 맞는 나라까지 빼는 지나치게 엄격한 버전
- **주로 볼 것은 `unsure46`**: 검증으로 확인된 나라는 남기고 확인 안 된 나라만 뺌
- `unsure46`의 19개국: BEN BLZ CAF CIV ERI FIN GAB NGA NPL PAK SEN SUR TUN TZA UGA URY VCT WSM ZMB (아프리카 11)

### 비교 기준: 같은 수를 무작위로 뺐을 때

도입국을 빼면 그 자체로 검정력이 떨어져 p가 커짐. 그래서 같은 수의 도입국을 무작위로 200번 빼 보고 비교함

- `gap_diff` = 가짜 세계 평균 연도 차 − 실제 평균 연도 차. 클수록 같은 그룹끼리 시기가 가까움
- `rand_share_below` = 무작위로 뺐을 때 `gap_diff`가 이번보다 작게 나온 비율. **작을수록(예: 0.05 미만) 이 나라들이 효과를 만들고 있었다는 뜻**
- `rand_share_p05` = 무작위로 뺐을 때 p < 0.05가 나온 비율 (검정력 참고)

## 해석

- **대륙, 언어・식민, 지역기구는 유지됨**: 연도가 확인 안 된 19개국을 빼도 유의하고, 효과 크기도 무작위로 뺐을 때와 비슷함
- **국경・무역 효과는 연도가 불확실한 나라에 기대고 있음**: 19개국을 빼면 효과가 거의 사라지고, 무작위로 같은 수를 뺐을 때보다 훨씬 많이 줄어듦 (3%, 1%, 3%). 이 나라들(아프리카 11개국 등)이 서로 이웃・교역 상대이면서 DB 연도가 가까움 → 실제로 같이 도입했을 수도, DB 연도가 같은 방식으로 틀렸을 수도 있음. **발표에서 국경・무역 결과는 이 한계와 같이 말해야 함**
- `excl46`처럼 맞다고 확인된 나라까지 다 빼면 대륙 말고는 다 사라지지만, 무작위 비교로 보면 상당 부분은 도입국이 68개로 줄어 검정력이 떨어진 탓
- 계층 10개 × 버전 4개를 봤으므로 p 0.03 근처 하나하나에 큰 의미를 두지 않음

## 한계
