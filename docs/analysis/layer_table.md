# 계층 비교표 (D, 11/23)

`python analysis/layer_table.py` → `analysis/layer_table.csv` (계층 10개 한 줄씩)

## 왜 하나

- 계층마다 연결이 얼마나 촘촘한지가 크게 다름 → 1단계가 실제로 비교하는 도입국 쌍 수도 크게 다름
- 쌍이 적은 계층은 같은 크기의 효과라도 p가 크게 나옴 → **계층끼리 p를 바로 비교하면 안 됨**. 이 근거를 숫자로 보여 줌
- 발표 '네트워크 만들기' 슬라이드용 (계층마다 어떤 네트워크인지 한 표로)

## 방법

- 구조 지표는 `common.structure(layer_graph(edges, nodes))` 그대로 (새로 짠 계산 없음, 무작위 섞기 없음)
- 연결된 도입국・도입국 쌍은 각 계층 `result_*.csv`의 `ALL` 줄(`n_adopters`, `n_pairs`)을 그대로 옮김
- `analysis` 열: `기본` / `보조`. 서현의 `layers/language/summary_language_colony.csv`와 같은 방식. 무역 k = 3・10은 `보조`(k 민감도), 무역 기본은 k = 5

| 열 | 뜻 |
|---|---|
| `nodes` | 204개국 전부 (`layer_graph`가 `nodes.csv` 전체를 넣음) |
| `edges` | 연결된 나라 쌍 수. 그룹을 여러 개 공유하는 쌍도 하나로 셈 |
| `density` | 엣지 ÷ 가능한 쌍 20,706 |
| `avg_degree` | 나라 하나당 평균 연결 수 (2 × 엣지 ÷ 204) |
| `components` | 서로 이어진 덩어리 수 (고립국도 하나씩 셈) |
| `isolates` | 연결 0개인 나라 |
| `clustering` | 평균 군집계수: 내 이웃끼리도 연결된 비율 |
| `adopters_linked` | 같은 계층 안에 연결된 도입국이 하나라도 있는 도입국 수 |
| `adopter_pairs` | 1단계에서 연도 차이를 비교하는 도입국 쌍 수 |

## 해석

- **밀도가 계층마다 수십 배 다름**: 소득 0.2507 vs 무역 k = 5 0.0082 → 약 31배. 언어도 무역의 약 18배
- **1단계가 비교하는 도입국 쌍도 그만큼 다름**: 소득 1,584쌍, 언어 1,257쌍 vs 무역 60쌍 (약 26배, 21배) → 쌍이 적은 무역・국경은 효과가 있어도 p가 크게 나오기 쉬움. **"언어 p가 무역 p보다 작다 = 언어 효과가 더 크다"로 읽으면 안 됨** → 효과 크기(몇 년 더 가까운가, `validation.md` 3장)와 같이 봄
- **그룹으로 묶은 계층 vs 쌍으로 정한 계층**
  - 대륙・소지역・소득은 그룹 안을 다 잇는 투영이라 군집계수가 1에 가까움 (0.990~1.000), 덩어리도 몇 개뿐 (5~24)
  - 국경・무역은 쌍으로 정한 계층이라 듬성듬성함: 군집계수 0.19~0.37, 고립국 48・51개
  - 언어・식민・지역기구는 그 사이 (군집계수 0.69~0.82)
- **무역은 k에 따라 구조가 크게 바뀜**: k = 3이면 204개국 중 90개국이 고립, 도입국 쌍 32개뿐 → k = 3에서 1단계 효과가 안 보이는 것(p 0.403, `trade.md`)은 표본이 작은 탓도 있음

## 다른 문서와 숫자가 다른 곳

- **지역기구 엣지・평균 degree**: `region.md`는 1,620 / 15.9 (그룹을 여러 개 공유하는 쌍을 여러 번 센 엣지 파일 줄 수 기준, 본문에 "중복 뺀 쌍 1,483"도 있음). 이 표는 쌍 하나를 한 번만 세므로 1,483 / 14.54. 둘 다 맞는 계산이고 기준만 다름
- 언어도 같은 이유로 엣지 파일 3,019줄 → 2,979쌍 (`language.md`와 같음)
- 나머지 엣지・평균 degree・고립국은 `region.md`・`income.md`・`language.md`・`trade.md`와 같음
