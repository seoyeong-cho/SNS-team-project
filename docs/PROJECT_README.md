## 1. 프로젝트 개요

> 원래 위치: `README.md`

### 🍫 설탕세는 어떻게 퍼지는가

소셜네트워크과학 팀 프로젝트 (7팀, 팀장 서현)

121개국 설탕세 도입(현행 DB 117 + 폐지・누락 보충 4)을 5개 분야 연결(지역, 언어・식민, 소득, 지역기구, 무역) 위에 놓고, 같은 그룹 나라끼리 도입 시기가 우연보다 더 묶이는지 가짜 세계 1,000개와 비교해 검증함. 나라끼리 따라 한 것(확산)인지, WHO 권고 같은 공통 원인에 다 같이 반응한 것인지 구분하는 게 목표.

- 설계서・설명서: 노션 (팀 링크 참고)
- **역할 분담 (누가 무엇을, 진행 상황): [docs/ROLES.md](ROLES.md)**
- 일정: 슬라이드 11/30(월) 23:59, 발표 12/7(월) 2일차 첫 번째 (15~20분 + 질의응답 5분, 질의응답은 팀원 전체), 최종 제출 12/18(금) 23:59 (보고서・코드・데이터・data description・산출물 실명제), 동료평가 12/20(일)

#### 각자 건드리는 곳

- 자기 폴더 `layers/<분야>/`만 수정. 남의 폴더는 PR 코멘트로 말하기
- `src/common.py`, `data/processed/`는 A만 수정. 함수가 더 필요하면 이슈로 요청
- `data/raw/`의 원본 파일은 받은 그대로 둠. 바꿀 게 있으면 변환 스크립트로

#### 계층 파일 형식 (꼭 지킴)

| 파일 | 열 | 규칙 |
|---|---|---|
| `layer_<이름>_groups.csv` | `iso3, group` | 한 나라가 그룹 여러 개면 행 여러 개 |
| `layer_<이름>_edges.csv` | `src, dst, group` | `src < dst`, 중복 없음, 자기 자신 연결 없음 |
| `result_<이름>.csv` | `group, n_adopters, n_pairs, mean_gap_real, mean_gap_fake_avg, p` | `stage1()` 결과 그대로 |

- 그룹으로 묶이는 분야(언어, 소득 등)는 `groups_to_edges()`로 엣지 생성
- 쌍으로 정의되는 분야(국경, 무역 상위 교역국, 식민 종주국-식민지)는 엣지 표를 직접 만들고 `group` 열에 관계 이름(예: `border`, `top5_trade`, `colony_FRA`)
- 제출 전 `check_edges(edges, nodes)` 통과해야 함

#### 1단계 계산

- `common.py`의 `stage1()`만 씀. 각자 따로 짜면 넷 결과를 비교할 수 없음
- 가짜 세계 seed는 42, 개수 1,000 고정 (`common.py`에 있음)
- 손으로 고친 매칭(국가명 → iso3 등)은 `layers/<분야>/manual_fixes.csv`에 이유와 함께 적기

#### 강건성 검사 (각자 계층마다 같이 냄)

기본 가짜 세계는 '해마다 몇 개국 도입했는지'만 맞추고 나머지는 전부 섞음. 그래서 소득이나 도입 목적처럼 도입 시기에 영향을 주는 나라 성격이 같은 그룹에 몰려 있으면, 따라 한 게 없어도 같은 그룹끼리 연도가 가깝게 나올 수 있음.

→ `robustness(edges, nodes)`로 같은 성격끼리만 섞은 가짜 세계에서 다시 검사. 결과는 `robustness_<이름>.csv`

| shuffle | 섞는 방식 | 거르는 요인 |
|---|---|---|
| `basic` | 도입국 전체에서 섞음 | 세계적 유행 (WHO 2016 등) |
| `income_db` | 같은 소득 등급끼리만 | 소득 수준 |
| `budget_year` | 예산법 연도 의심 여부끼리만 | 기존 소비세가 설탕세로 집계된 경우 |
| `health_obj` | 건강 목적 여부끼리만 | 도입 목적 (건강 vs 세수) |

- 기본에서 작던 p가 어떤 줄에서 커지면 → 그 효과 일부는 그 성격 때문이라고 해석
- 네 줄 다 작으면 → "세계적 유행, 소득, 도입 목적으로 설명되는 것보다 더 묶였다"고 말할 수 있음
- 같은 지역에 한꺼번에 온 외부 충격(예: 지역 단위 세무 개혁 권고)은 어떤 섞기로도 못 거름. 결론에 "따라 했다"고 쓰지 않는 이유
- `follow_test(..., strata="income_db")`처럼 따라 함 검사에도 같은 옵션 있음

#### 도입 여부 검사 (각자 계층마다 같이 냄)

1단계는 도입국끼리 '시기'만 봐서 미도입국 83개국이 빠짐. 그런데 '같이 안 한 것'도 패턴임 (예: 한국・일본・중국 모두 미도입)

→ `adoption_test(edges, nodes)`로 204개국 전부의 도입 여부(0/1)를 섞어서 "같은 그룹 쌍 중 도입 여부가 같은 비율"을 가짜 세계와 비교. 결과는 `adoption_<이름>.csv`

- `same_status_real`이 `same_status_fake_avg`보다 크고 p가 작으면 → 같은 그룹끼리 같이 하거나 같이 안 함

### 도입 연도・설탕세 판단 기준 (팀 공통)

연도 검증, 폐지・누락 보충, 새 나라 추가 등 **도입 연도를 다루는 모든 작업에 적용**함 (2026-11-17 정함)

#### 설탕세로 치는 것

- **넣음**: 가당・탄산・청량음료를 콕 집어 따로 매기는 세금・부과금. 소비세, 수입관세・부과금, 부담금, 음료만 올린 VAT 차등 세율 모두 포함. **목적(세수/건강)은 따지지 않음** → World Bank DB 정의와 같음
- **뺌**: 모든 상품 또는 음료 전체에 같은 세율로 붙는 일반 소비세・부가세 (음료가 그 안에 섞여 있을 뿐인 것)
- 건강 목적 여부는 `health_obj` 열로 따로 다룸 (강건성 검사). 법을 만든 이유를 못 찾으면 근거 칸에 "목적 미확인"으로 남김

#### 도입 연도

- **도입 연도 = 위 기준에 맞는 세금이 그 나라에 처음 생긴 해**. 나중의 세율 인상, 법 개정, 법 통합・대체(예: 옛 소비세법을 새 법으로 바꾼 해)는 도입 연도가 아님
- **`year_checked` = 시행 연도** (본 분석에 씀). DB `year_imp`와 같은 기준이라 114개국이 통일됨
- **`year_enacted` = 제정・공포 연도** (예산법이면 그 예산법이 의회를 통과・공포된 해). '아이디어가 그 나라에 건너온 시점'에 더 가까움 → 같이 기록하고 강건성 검사로 씀
  - 예: 영국 2016 발표 → `year_enacted` 2017 (Finance Act 2017) → `year_checked` 2018 (시행)
  - 예: 베냉 loi de finances 2011년 12월 공포, 2012 회계연도 → `year_enacted` 2011, `year_checked` 2012
- **한 기준을 일부 나라에만 쓰지 않음**. 분석은 나라 쌍의 연도 차이를 보므로 시행・제정 연도가 섞이면 결과가 흔들림. 제정 연도로 본 분석을 하려면 전체를 다 모은 뒤 바꿈
- 발의 연도는 나라마다 기록이 고르지 않아 쓰지 않음

## 8. 추가 검증 계획

> 원래 위치: `analysis/validation/README.md`

### 추가 검증 계획 (순열검정 신뢰성・확산 해석)

팀 컨펌 완료 (2026-11-17). 기존 분석 방향・로드맵(1단계 → 2단계 → 2-1단계 → 3단계)은 그대로 두고, 그 위에 **검증만 추가**함.

#### 작업 원칙

1. 기존 코드・결과 파일은 수정・삭제하지 않음. 새 코드와 결과는 전부 `analysis/validation/` 안에만 둠
2. `src/common.py`, `data/processed/`는 A만 수정함 → 여기서는 **import해서 읽기만 함**. 필요한 열(예: 대륙)은 스크립트 안에서 메모리에만 붙이고 파일에 저장하지 않음. `common.py`에 넣을 만한 기능은 이슈로 A에게 제안
3. 남의 계층 폴더(`layers/<분야>/`)는 결과 csv를 **읽기만** 함
4. 가짜 세계 seed 42 고정 (`common.SEED`). 실제 데이터 검증은 R = 1,000, 시뮬레이션은 계산량 때문에 R = 499 (p 최소값 0.002)
5. 유의한 결과 = "같은 그룹끼리 시기・도입 여부가 우연보다 묶임"까지만 말함. **나라끼리 따라 했다(인과적 확산)고 단정하지 않음**
6. 각 검증마다 목적・귀무가설・비교 기준・해석 한계를 아래 표대로 적고 결과 보고

| 46개국 **제외** 후 재분석 | `pilot/layers5.py` | ⚠️ 파일럿만 | 보충 전 112개국 기준. 현재 114개국 기준으로는 아직 안 함 |
| 다중검정 보정 | 이 문서 7장 (2-1단계) | ⚠️ 계획만 | 2-1단계는 Bonferroni(0.05 ÷ 검사 수) 예정. **1단계 그룹별 p는 보정 없음** |
| 효과 크기・순열분포 | – | ❌ 없음 | 실제 평균 vs 가짜 평균만 있음 |
| 그룹 동일 가중 평균 | – | ❌ 없음 | `ALL`은 쌍 가중 → 대륙 `ALL`의 1,456쌍 중 아프리카가 780쌍(54%) |
| 작은 그룹 안정성 | – | ❌ 없음 | 소지역에 도입국 2개(1쌍)짜리 그룹 있음 |
| 정답 아는 가상 데이터 검증 | – | ❌ 없음 | |
| 대륙 안에서만 섞기 | – | ❌ 없음 (기능은 위처럼 바로 가능) | |
| 미도입국 포함 후속 도입 분석 | – | ❌ 없음 | |

##### `follow_test`가 실제로 하는 계산

```
d[a, b] = a 도입 연도 − b 도입 연도
도입국 a마다: 연결된 나라 b 중 하나라도 1 ≤ d ≤ 3 이면 '따라 함' 표시
통계 = 표시된 도입국 비율 (114개국 중)
가짜 세계 = 도입국끼리 연도를 전체에서 섞음 (strata 주면 그 안에서)
```

한계
- **미도입국이 빠짐**: 이웃이 도입했는데도 안 따라 한 나라(반례)를 못 셈
- **위험 집합이 없음**: "그 해에 아직 도입 안 한 나라들 중에서" 비교하지 않음
- **전체 섞기라 지역별 시기 차이가 가짜 세계에서 사라짐** → 같은 지역에 공통 충격이 있으면 '따라 함' 비율이 부풀 수 있음 (시나리오 S2에서 확인)
- 같은 해 도입(d = 0)은 안 셈, 이웃 몇 개가 도입했는지(노출 강도)도 안 봄

#### 3. 검증별 구체적 방법

##### V1. 순열검정 자체의 신뢰성 (가상 데이터 실험)

**공통 설정 (가정)**
- 나라 204개와 실제 연결 구조(대륙・소지역 엣지, 언어 계층이 나오면 언어 엣지)를 그대로 씀. 연도만 가상으로 만듦
- 1990~2023 연 단위 이산시간 모형: 아직 도입 안 한 나라 i가 t년에 도입할 확률 = `h_it`
- 기본 확률 `h0_t`는 실제 연도별 도입 수에 맞춤 → 가상 데이터의 도입국 수 ≈ 114, 연도 분포 ≈ 실제
- 폐지 없음, 연결은 시간에 따라 안 바뀜
- 시나리오마다 가상 데이터 500세트 × 가짜 세계 499개

| 시나리오 | 생성 규칙 | 정답 | 확인하는 것 | 검증하는 기존 분석의 한계 |
|---|---|---|---|---|
| **S0 영향 없음** | `h_it = h0_t` (모든 나라 같음) | 효과 없음 | 유의 비율(1종 오류)이 0.05 근처인지 | 구현 오류, p값 계산 방식 점검. 전체 섞기는 이 상황에서 교환 가능성이 성립하므로 ≈ 5%가 나와야 정상 |
| **S1 연결 국가끼리 영향** | `h_it = h0_t × (1 + β·E_it)`, `E_it` = 연결된 나라 중 t−3 ~ t−1년 도입국 있음(0/1). β = 0.5, 1, 2, 4 | 확산 있음 | β별 검출 비율(검정력) | 표본 114개국으로 실제 확산을 얼마나 잡는지 → "따라 함 흔적 없음"이 **효과 없음인지, 검정력 부족인지** 판단 근거 |
| **S2 지역 공통 충격** | 확산 없음. 대륙 c마다 도입 확률이 높아지는 시기(정점 연도 `m_c`)를 다르게 둠: `h_it = h0_t × exp(−(t−m_c)²/2σ²)` 형태 | 확산 없음, 대륙별 시기 차이만 있음 | ① 대륙 1단계는 유의해야 정상(시기 동조는 실제로 있음) ② `follow_test`가 '따라 함'으로 잘못 잡는 비율 ③ 대륙과 겹치는 계층(예: 언어)의 1단계 오탐 비율: 전체 섞기 vs 대륙 안 섞기 ④ V3 통계의 오탐 비율 | **공통 원인을 확산으로 오인하는 정도.** 기존 1단계・`follow_test`가 이 둘을 구분 못 한다는 한계를 숫자로 보여줌 |

**결과 정리**
- 시나리오 × 검정 × (β) 별 유의 비율 (α = 0.05) + 95% 신뢰구간 (500회 이항)
- 효과 크기 분포: `gap_diff = 가짜 평균 − 실제 평균`(년), `z = gap_diff / 가짜 표준편차`의 상자그림
- 실제 데이터의 `gap_diff`가 S1, S2 분포 중 어디에 가까운지 같이 표시 (참고용, 판정 아님)

**한계**: 가상 데이터는 우리가 정한 생성 규칙만큼만 현실적임. S1의 노출 창(1~3년)과 S2의 충격 모양은 가정이므로 결과는 "이런 가정에서 이 검정은 이렇게 행동한다"로만 말함

##### V2. 대륙 안 조건부 순열검정

- **목적**: 대륙과 겹치는 계층(언어・식민, 지역기구, 소지역, 국경 등)의 효과가 대륙별 시기 차이만으로 설명되는지 확인
- **귀무가설**: 대륙이 같다는 조건에서, 도입 연도는 그 계층의 그룹과 무관함 (같은 대륙 도입국끼리는 연도를 바꿔도 됨)
- **방법**: `nodes = load_nodes()` 후 메모리에서 `nodes["continent"] = countries.json region` 추가 → `stage1(edges, nodes, strata="continent")`, `follow_test(..., strata="continent")`. `common.py`는 수정 안 함
- **비교**: 계층마다 `basic` 결과 옆에 `continent` 결과를 같은 표에 놓음

| basic | continent | 해석 |
|---|---|---|
| 유의 | 유의 | 대륙 시기 차이를 넘어 그 계층 그룹끼리 시기가 묶임 (인과는 아님) |
| 유의 | 유의 아님 | 그 계층 효과는 대륙별 시기 차이로 대부분 설명됨 |
| 유의 아님 | – | 원래 효과 없음 |

- **적용 제외**: 대륙 계층 자체. 대륙 안에서 섞으면 같은 대륙 쌍의 연도 집합이 그대로라 통계가 항상 같음(p = 1) → 대륙 효과 검정은 기존 전체 섞기만 사용
- **주의**: 도입국이 적은 대륙(오세아니아 13, 유럽 17)은 섞을 수 있는 경우의 수가 적어서 검정력이 낮음. 결과에 대륙별 도입국 수를 같이 적음

##### V3. 미도입국 포함 후속 도입 분석

- **목적**: "먼저 도입한 나라와 연결돼 있으면, 아직 안 한 나라가 그다음 해에 도입할 가능성이 높은가"를 미도입국까지 넣어서 확인
- **귀무가설**: 같은 연도・같은 대륙 안에서, 연결된 나라의 최근 도입 여부는 그 해 도입과 무관함

**데이터 구성 (나라-연도 위험 집합)**
- 행 = (나라 i, 연도 t), t = 1990~2023. i가 t년 **시작 시점에 아직 미도입**이면 포함 (미도입국 83개국은 모든 해 포함)
- 결과 `Y_it` = t년에 도입하면 1, 아니면 0. 도입한 다음 해부터는 위험 집합에서 빠짐
- 노출 `E_it` = 계층 엣지로 연결된 나라 중 t−3 ~ t−1년에 도입한 나라가 있으면 1 (보조: 연결된 나라 중 t년 이전 도입 비율)
- 1990년 전 도입국(브라질, 덴마크, 노르웨이 등): 위험 집합에서는 제외, 노출을 주는 쪽으로만 씀. 폐지국(노르웨이 2021, 이스라엘 2023)은 폐지 전까지만 노출원 → 폐지 후에도 노출원으로 두는 경우와 비교

**연도 추세・지역 차이 반영**: (연도 × 대륙) 층 안에서만 비교
- 통계 `T = Σ_층 (노출된 나라 중 실제 도입 수 − 층 안 도입률로 기대되는 도입 수)` (Mantel–Haenszel 방식). numpy로 계산, **새 패키지 필요 없음**
- 가짜 세계: 대륙 안에서 도입 연도(미도입 = '없음' 포함)를 섞음 → 대륙별・연도별 도입 수가 정확히 유지되고, 누가 언제 했는지만 바뀜. 각 가짜 세계마다 노출을 다시 계산해서 T 분포를 만듦
- 보조 지표: Mantel–Haenszel 오즈비 (효과 크기)

**연결 관계 정의 (검증 가능한 범위만)**
| 계층 | 연결 | 사용 여부 |
|---|---|---|
| 소지역・국경 | `layers/region` 엣지 (시간 불변) | ✅ |
| 언어・식민 | B의 엣지 (시간 불변) | ✅ (B 결과 나오면) |
| 지역기구 | 가입 연도가 있으면 연도별, 없으면 현재 회원 기준 | ⚠️ 현재 기준이면 한계로 적음 |
| 소득 | `income_db`는 DB 작성 시점 등급, 도입국만 있음 → 사용 안 함. C의 연도별 등급이 나오면 사용 | ⚠️ |
| 무역 | D의 엣지 (2010~2020 평균, 시간 불변). 2010년 이전 도입국에겐 도입 이후 교역 관계 | ⚠️ 한계로 적음 |
| 대륙 | 층으로 이미 통제하므로 노출 계층으로는 안 씀 | ❌ |

**한계**: 사건 수가 114개뿐이라 검정력이 낮음(V1 S1 결과로 수준 제시). 연결이 시간에 따라 안 바뀐다고 가정. 공통 충격이 대륙보다 작은 단위(소지역 단위 세무 개혁 권고 등)로 오면 걸러지지 않음 → 유의해도 "연결된 나라의 최근 도입과 **연관**"까지만 말함

| 다중검정 보정 | 계층 안 그룹별 p(`ALL` 제외)에 Benjamini–Hochberg(FDR 5%) 적용, `p_bh` 열 추가. 계층 전체 `ALL` p는 주 결과로 따로 보고 | 보정 전후 유의 그룹 수 | 2-1단계 Bonferroni는 B 계획대로 유지, 1단계 그룹별에만 추가 |
| 효과 크기・순열분포 | `gap_diff`(년), `z`, 가짜 분포 2.5~97.5% 구간 추가. 계층별 순열분포 히스토그램에 실제값 선 표시 | p만이 아니라 "몇 년 더 가까운가"로 보고 | 새로 함 (기존 `stage1` 출력은 그대로 두고 별도 계산) |
