## 한 장 요약

**무엇을 하나:** 117개국이 설탕세(당이 든 음료에 매기는 세금)를 도입했습니다. 이 세금이 어떤 길을 따라 퍼졌는지 찾습니다. 길의 후보는 지역, 언어, 소득 수준, 통화, 지역기구 같은 **분야**입니다. 팀원이 분야를 하나씩 맡습니다(처음 아이디어에서 "layer"라고 부른 것).

**어떻게 하나:** 분야마다 "같은 그룹 나라끼리 도입 연도가 평균 몇 년 차이 나는가"를 잽니다. 이 값을 도입 연도를 제비뽑기로 섞은 가짜 세계 1,000개와 비교해서, 가짜보다 확실히 가까울 때만 "그 분야 안에서 같이 움직였다"고 봅니다. 예를 들어 아랍어권 11개국은 평균 4.5년 차이로, 가짜(약 9.1년)보다 가깝습니다. 마지막으로 다섯 분야를 한꺼번에 비교합니다. 분야끼리 겹치는 부분(예: 아랍어권은 대부분 중동)을 빼고 각 분야의 몫을 계산해서, 어느 분야가 가장 영향이 큰지 순위를 매깁니다.

**왜 이렇게 하나:** "가까운 나라라서 퍼졌다"만 보면 다른 길을 놓칩니다. 분야를 미리 하나로 정하지 않고, 모두 같은 방법으로 확인한 뒤 비교합니다.

**지금까지 결과(파일럿, 4개 분야):** 지역 안에서는 같이 움직인 흔적이 뚜렷합니다. 언어는 지역과 겹치는 부분을 빼면 약해지고, 소득·통화는 흔적이 없습니다. 다섯 번째 분야(지역기구)는 데이터를 모은 뒤 추가합니다.

**한 문장 메시지(예상):** 설탕세는 같은 말이나 같은 소득보다 같은 지역을 따라 비슷한 시기에 도입됐다.

## 네트워크 만들기

분야마다 네트워크를 하나씩 만듭니다. 방법은 수업에서 배운 **이분 네트워크 투영**입니다.

1. 나라와 그룹을 잇습니다. 예: 모로코 — 아랍어, 모로코 — 아프리카. (나라–그룹 이분 네트워크)
2. 같은 그룹에 속한 나라끼리 직접 잇습니다. (투영)
3. 분야마다 나라–나라 네트워크가 하나씩 생깁니다. 각자 맡은 분야가 **계층 하나**입니다.
4. 모든 계층에 같은 204개국이 들어 있으므로, 이것들을 묶으면 교재의 **멀티플렉스 네트워크**입니다.
5. 계층을 합치면 **가중치 네트워크**가 됩니다. 두 나라 사이 가중치 = 같은 그룹인 분야 수(0~4)입니다. 교재 설명처럼 합치면 "어느 분야에서 같은지"라는 정보는 사라지므로, 계층별 분석과 합친 분석을 둘 다 합니다.

**예시: 4개국**

| 나라 | 언어 | 대륙 |
|---|---|---|
| 사우디 | 아랍어 | 아시아 |
| 모로코 | 아랍어 | 아프리카 |
| 세네갈 | 프랑스어 | 아프리카 |
| 프랑스 | 프랑스어 | 유럽 |

언어 계층 인접행렬 (1 = 연결):

| | 사우디 | 모로코 | 세네갈 | 프랑스 |
|---|---|---|---|---|
| 사우디 | 0 | 1 | 0 | 0 |
| 모로코 | 1 | 0 | 0 | 0 |
| 세네갈 | 0 | 0 | 0 | 1 |
| 프랑스 | 0 | 0 | 1 | 0 |

대륙 계층에서는 모로코–세네갈만 연결됩니다. 두 계층을 합친 가중치 네트워크에서는 사우디–모로코 1, 세네갈–프랑스 1, 모로코–세네갈 1입니다. 같은 4개국이라도 분야마다 연결이 완전히 달라지는 것을 보여주는 예시입니다.

**주의:** 분야마다 네트워크 크기가 다릅니다. 영어 공용어 나라는 66개국이라 언어 계층에서 한 나라가 평균 32개국과 연결됩니다. 반면 통화 계층에서는 120개국이 아무와도 연결되지 않습니다(자기 나라 통화만 씀). 그래서 계층마다 노드 수, 엣지 수, 밀도, 평균 degree, 컴포넌트 수를 표로 나란히 보여주고, 결과를 해석할 때 이 차이를 함께 설명합니다.

## 분석 방법 3단계

**1단계. 분야마다 "그 안에서 같이 움직였나" 확인**

- 계층에서 연결된 도입국 쌍마다 도입 연도 차이를 구하고 평균을 냅니다. 평균이 작을수록 "같은 그룹끼리 비슷한 시기에 도입했다"는 뜻입니다.
- 비교 기준을 만듭니다. 도입 연도를 제비뽑기하듯 나라들에게 무작위로 다시 나눠주고 같은 계산을 합니다. 이걸 1,000번 반복합니다. 누가 도입했는지, 해마다 몇 개국이 도입했는지는 그대로 두고 "누가 언제"만 섞습니다.
- 실제 값이 가짜 1,000개 중 거의 없을 만큼 작으면(p 값이 작으면) "그 분야 안에서 같이 움직인 흔적이 있다"고 봅니다.

**2단계. 다섯 분야 한꺼번에 비교하기**

1단계는 분야마다 따로 봅니다. 그런데 분야끼리 겹치면 점수가 부풀려집니다. 예를 들어 아랍어권은 대부분 중동·북아프리카라서, 언어 점수가 높아 보여도 사실은 지역 덕일 수 있습니다. 그래서 세 가지를 합니다.

- **겹침 표:** 다섯 분야끼리 "같은 그룹인 나라 쌍"이 얼마나 겹치는지 5×5 표로 보여줍니다. 멀티플렉스의 계층끼리 엣지가 얼마나 겹치는지 보는 것과 같습니다.
- **각 분야의 몫 나누기:** 나라 쌍마다 "다섯 분야 중 어디서 같은 그룹인지"와 "도입 연도 차이"를 적습니다. 다섯 분야를 한꺼번에 넣고, 각 분야가 같으면 연도 차이가 몇 년 줄어드는지를 동시에 계산합니다(회귀). 겹치는 부분은 자동으로 나눠지므로, 남는 값이 그 분야만의 몫입니다. 이 값도 가짜 세계 1,000개와 비교합니다.
- **가중치 네트워크:** 계층을 합쳐서 "공유하는 분야가 많을수록 연도 차이가 작아지나"를 봅니다.

이렇게 나온 "각 분야의 몫"으로 순위를 매기면, 그게 "어느 분야가 가장 영향이 큰가"의 답입니다.

**3단계. 퍼진 모양 보기**

- **확산 곡선:** 그룹별로 x축 연도, y축 누적 도입 비율(%)을 그립니다. 몇 년 만에 몰리면 급격형, 오래 걸리면 점진형입니다.
- **확산 경로:** 같은 그룹 안에서 "먼저 도입한 나라 → 나중 나라"를 화살표로 잇습니다. 반드시 무작위 연도로 만든 가짜 경로를 옆에 같이 보여줍니다. 화살표는 "순서"일 뿐이고, "이 나라가 저 나라에 영향을 줬다"는 증거가 아니기 때문입니다.
- **시간 네트워크:** 연도별로 도입국이 늘어나는 지도는 교재의 시간 네트워크(연도 하나 = 스냅샷 하나)로 설명합니다.

**미리 정해둘 규칙**

- 분야 목록과 판단 기준은 11/15까지 정하고 바꾸지 않습니다. 결과를 보고 기준을 바꾸면 원하는 결과를 만들어내는 것이 됩니다.
- 분야가 5개 안팎이면 p < 0.01을 "뚜렷하다", 0.01~0.05를 "약하다"로 부릅니다.

## 지금까지 나온 결과 (파일럿)

지역은 뚜렷하고, 언어는 지역에 업혀 있고, 소득·통화는 흔적이 없습니다. 올려주신 파일로 직접 계산했고, 1990~2023년 도입 112개국 기준입니다. 가짜 세계에서 같은 그룹 나라끼리의 평균 연도 차이는 약 9.1년입니다.

**1단계: 분야별**

| 분야 | 같은 그룹끼리 평균 연도 차이 | p | 판단 |
|---|---|---|---|
| 대륙 | 8.0년 | 0.001 | 뚜렷함 |
| 언어 (영어·프랑스어·아랍어·스페인어·포르투갈어) | 8.1년 | 0.03 | 약함 |
| 소지역 | 8.3년 | 0.06 | 없음에 가까움 |
| 소득 수준 (도입국만) | 9.3년 | 0.78 | 없음 |
| 통화 | 11.0년 | 0.97 | 없음 (오히려 흩어짐) |

**그룹별로 나눠 보면**

- 아랍어권 11개국: 4.5년(p 0.02). 빨리 몰려서 도입했습니다.
- 포르투갈어권 6개국: 3.1년(p 0.03). 단, 나라 수가 적습니다.
- 스페인어권 17개국: 12.7년. 중남미는 30년에 걸쳐 천천히 도입했습니다.
- 소득: 저중소득국만 7.5년(p 0.07)으로 조금 모여 있고, 고소득국은 10.6년으로 흩어져 있습니다.

**2단계: 4개 분야 한꺼번에 비교 (지역기구는 데이터 수집 후 추가)**

분야끼리 겹침 (같은 그룹인 나라 쌍이 얼마나 겹치나, 0~1):

| | 대륙 | 언어 | 소득 | 통화 |
|---|---|---|---|---|
| 대륙 | — | 0.23 | 0.24 | 0.08 |
| 언어 | 0.23 | — | 0.13 | 0.05 |
| 소득 | 0.24 | 0.13 | — | 0.05 |
| 통화 | 0.08 | 0.05 | 0.05 | — |

각 분야의 몫 (겹치는 부분을 뺀 뒤, 같은 그룹이면 가짜보다 몇 년 더 가까운가):

| 순위 | 분야 | 가짜보다 가까운 정도 | p | 판단 |
|---|---|---|---|---|
| 1 | 대륙 | 1.5년 | 0.002 | 뚜렷함 |
| 2 | 언어 | 1.0년 | 0.06 | 약함 |
| 3 | 소득 | −0.4년 | 0.95 | 없음 |
| 4 | 통화 | −2.7년 | 0.99 | 없음 (오히려 흩어짐) |

겹치는 부분을 빼도 대륙이 1위입니다. 언어는 따로 볼 때보다 약해져서 "있다"고 말하기 어려운 경계에 있습니다. 지금까지는 "같은 말이라서"보다 "같은 지역이라서"에 가깝습니다.

**계층을 합친 가중치 네트워크**

대륙·언어·소득·통화 4개 계층을 합쳤을 때, 두 나라 사이 가중치 = 같은 그룹인 분야 수입니다.

| 공유하는 분야 수 | 나라 쌍 | 평균 연도 차이 |
|---|---|---|
| 0 | 3,180 | 9.7년 |
| 1 | 1,982 | 8.5년 |
| 2 | 793 | 8.9년 |
| 3 | 240 | 8.2년 |
| 4 | 21 | 8.9년 |

가짜 세계는 모두 약 9.1년입니다. 하나도 공유하지 않는 나라끼리는 더 떨어져 있고, 하나라도 공유하면 가까워집니다. 하지만 많이 공유할수록 계속 가까워지지는 않습니다. 분야를 더 모으면 다시 확인합니다.

이 결과는 탐색 단계입니다. 소득은 도입 안 한 나라 정보가 아직 없고, 종교·지역기구·무역은 데이터를 모은 뒤에 같은 표에 한 줄씩 추가합니다.

## 수업에서 배운 것과의 연결

## 한계 (발표에서 먼저 말할 것)

- **"비슷한 시기"까지만 알 수 있습니다.** 누가 누구를 따라 했는지는 모릅니다. 같은 지역에 같은 시기 공통 요인(지역기구 합의, WHO 권고 등)이 있어도 같은 결과가 나옵니다.
- **도입 연도가 완벽하지 않습니다.** 같은 DB의 버전마다 13개국 연도가 다릅니다.
- **폐지된 세금은 빠져 있습니다.** 예: 덴마크, 노르웨이.
- **"설탕세"의 절반은 건강보다 세수 목적입니다.** 건강 목적은 52%입니다.
- **분야가 많으면 우연히 맞는 게 생깁니다.** 그래서 분야와 기준을 미리 정합니다.

## 예상 질문

1. **"비슷한 시기에 도입한 게 확산인가요?"** → 확산이라고 단정하지 않습니다. "그 분야 안에서 같이 움직인 흔적"까지만 말합니다.
2. **"무작위로 섞어 비교하는 이유는요?"** → 2017~2019년에 도입이 몰려서, 아무 나라나 묶어도 어느 정도는 비슷한 시기가 나옵니다. 그보다 더 모였는지를 봐야 합니다.
3. **"분야끼리 겹치는데 어떻게 구분했나요?"** → 다섯 분야를 한꺼번에 넣고 각 분야의 몫을 나눠 계산했습니다. 예를 들어 언어는 따로 보면 효과가 있어 보이지만, 지역과 겹치는 부분을 빼면 약해집니다.
4. **"계층마다 크기가 다른데 공정한 비교인가요?"** → 비교표로 크기를 먼저 보여주고, 그룹별로도 따로 봤습니다.
5. **"Lancet 논문과 뭐가 다른가요?"** → 그 논문(Lancet Global Health, 2026, 64개국)은 나라의 특성(소득·비만·당뇨)으로 도입을 설명했고, 우리는 나라 사이의 연결을 봅니다.
