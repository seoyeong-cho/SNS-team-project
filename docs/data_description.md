**전처리 (한 줄씩)**
- 공용어: Factbook "(official)" 표시 → 없으면 note → 그래도 없으면 `countries.json` (나라・언어 306행 중 Factbook 282, 보충 24)
- 지역・소수 단위 공용어는 뺌 (예: 카탈루냐어). 이름만 다른 같은 언어는 합침 (몰도바어 → 루마니아어 등)
- 사라진 제국(오스만・소련 등)은 같은 지배국 공유 연결만, 현대 국가와 직접 연결 안 함
- ICOW 원본・변환표는 재배포 금지 → git에 안 올리고 `fetch_external.py`로 받음

**발표에서 같이 말할 한계**
- 공용어 ≠ 실제 사용 언어. 정책 정보 흐름의 대리 지표로만 봄
- 식민 효과는 영국 연결에 기댐 (영국 연결 빼면 사라짐, 5-1장)

## 6. 무역 (승아, `docs/layers/trade.md` 0장)

| | 무역 계층 (`trade`, 기본 k = 5) |
|---|---|
| 출처 | UN Comtrade, HS 2202 (가당・향 첨가 음료). 수입(M) 기록 68,861행 (2026-11-18 받음) + 수출(X) 기록 67,126행 (2026-11-21 받음) |
| 시점 | 2010~2020년 연평균 하나 (시간 불변 계층). 2010년 전 도입국에게는 도입 이후 교역 |
| 나라 매칭 | 204 / 204 (nodes 코드 = Comtrade 코드). 교역 기록 없는 3개국(맨섬・리히텐슈타인・모나코)은 영국・스위스・프랑스 쪽에 포함돼 집계 → 고립국으로 둠 ('누락 국가') |
| 연결 만드는 법 | 나라 쌍 교역액(두 방향 연평균 합, 7,972쌍) → 나라마다 상위 k개국 → **서로** 상위 k 안이면 연결 |
| 그룹・관계 수 | 관계 1개 (`top5_trade`). 그룹이 아니라 쌍으로 정의 |
| 엣지 (쌍) | 169 (민감도: k = 3 85, k = 10 364) |
| 연결 있는 나라 / 고립 | 153 / 51 (k = 3 114 / 90, k = 10 188 / 16) |
| 밀도・평균 degree・군집계수 | 0.0082・1.66・0.185 |
| 도입국 쌍 / 연결된 도입국 | 60쌍 / 66개국 |

**전처리 (한 줄씩)**
- 나라끼리 거래만: World・선박 연료・자유무역지대・지역 미상 코드, nodes에 없는 지역(홍콩・마카오 등) 뺌 (수입 68,861 → 61,895행, 수출 67,126 → 59,097행)
- 방향(수입국 ← 수출국)마다 출처 하나로 11년 고정: 수입국이 11년 다 보고하면 수입 기록(82.8%), 아니면 수출국이 다 보고하면 수출 기록(14.2%), 둘 다 빈 해가 있으면 더 많이 보고한 쪽(3.0%)
- 연평균: 보고는 했는데 그 상대 기록이 없는 해 = 0, 보고 자체를 안 한 해 = 평균에서 뺌
- 교역액이 같으면 iso3 알파벳순 (돌릴 때마다 같게)

**발표에서 같이 말할 한계**
- 무역 효과는 k에 따라 흔들리고(k = 3 없음, k = 5 p 0.074, k = 10 p 0.023), 연도 불확실한 19개국을 빼면 사라짐
- '서로 상위 k' 조건이라 작은 나라는 고립되기 쉬움 (k = 5에서 51개국)
- 수입(CIF)・수출(FOB) 기록이 방향마다 섞임. 둘 다 있는 칸 중앙값 차이 4% 정도
